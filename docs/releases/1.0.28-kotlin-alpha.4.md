# FluxDown 1.0.28 Kotlin Android Alpha 4

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 修复 HTTP `416 Range Not Satisfiable` 场景：只有服务端明确证明本地文件完整时才复用，否则清理过期残留并重新下载；分片 Range 全部被拒绝时回退到单连接下载。
- Torrent/Magnet 任务列表统一显示资源目录入口，文件名、格式、大小和逐文件进度继续在“资源详情”中展示。
- 任务列表补齐 Rust 持久化的开始时间、完成时间和实时速度；完成任务不再显示误导性的下载速度。
- Android 前台服务和宿主进程恢复路径继续由 Rust canonical 队列驱动，强停后可恢复未完成任务且不会创建重复任务。
- 修正移动端 Alpha 发布流水线，使 `mobile-release` 构建并上传 Kotlin 原生 arm64 APK，而不是旧 Flutter APK。

## 验证范围

- Rust core：`116/116` 项通过；Rust FFI：`14/14` 项通过。
- Android Kotlin connected instrumentation：`10/10` 通过，覆盖 HTTP 416、Rust 回环队列、前台服务、二维码实体识别和 HLS remux。
- Redmi Note 8 Pro 真机（serial `wsvwypiz7xwslvl7`）已完成 arm64 Debug 安装启动和宿主强停恢复验证；任务最终 `67,108,864/67,108,864 B`，无重复任务。
- Release APK 使用 Android Debug 证书，仅用于迁移预览和真机测试，不代表正式商店签名。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 完整多音轨 rendition 选择、系统低内存回收和正式商店签名仍待后续环境验收。
