# FluxDown 1.0.28 Kotlin Alpha 2

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 修复 Android 多轨 TS 转 MP4 时 `MediaExtractor` 未重置游标的问题，避免音视频轨道缺失。
- 增加 Android 原生 TS→MP4 转封装成功校验，失败时保留原始 TS。
- 扫码识别兼容 ML Kit `displayValue`，并修复快速关闭扫码弹框时的异步相机绑定竞态。
- Rust HLS 对空媒体 playlist 直接返回失败，避免生成 0 字节成功任务。
- Torrent/Magnet 选中文件进度继续按确认文件集合统计，任务列表显示资源目录名。

## 验证

- Android 真机：Redmi Note 8 Pro，serial `wsvwypiz7xwslvl7`。
- HLS TS→MP4：`ts-remux-test-3.mp4`，`79.1 KB/79.1 KB`，任务进入已完成。
- Rust：core `109` 项、FFI `14` 项通过。
- Kotlin arm64 Debug 安装启动通过，无 `FATAL EXCEPTION`。
- Release APK 使用本机 Alpha 预览签名，仅用于迁移预览，不代表正式商店签名。

## 已知边界

- 二维码实体画面识别尚未完成真机闭环验证。
- Android 媒体栈尚无独立自动化测试目录，多轨/损坏 TS/超大媒体仍需扩展夹具。
- 本版本不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
