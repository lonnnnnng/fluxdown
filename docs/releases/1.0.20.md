## 主要修复

- 修复 iOS simulator 构建缺少 `libtorrent_flutter` 模拟器静态库的问题。构建前会按插件版本从上游 Git 标签补齐 `arm64`/`x86_64` simulator slice，并用 `lipo` 校验缓存完整性。
- 修复 iOS `AppDelegate` 异步读取存储占用时 `FlutterResult` 生命周期标注缺失导致的 Swift 编译错误。
- iOS 本地 simulator 构建命令统一使用 UTF-8 CocoaPods 环境，避免 macOS 默认 ASCII 编码导致 `unicode_normalize` 异常。

## 版本与发布

- 版本号统一为 `1.0.20`，移动端版本号为 `1.0.20+21`。
- 保留上一版移动端版本检查、更新日志、Android APK 下载入口及 Torrent/Magnet 跨端 metadata、多文件选择和任务详情能力。
- 发布流水线仍只在明确选择 `run_mode=release` 时执行；普通提交和标签推送不会自动发版。

## 验证边界

- 本地 `npm run mobile:ios:prepare` 已从 `libtorrent_flutter` `v2.0.0` 标签恢复 simulator slice，`lipo -info` 确认同时包含 `arm64` 与 `x86_64`。
- 本地 `npm run mobile:ios:simulator` 已成功生成 `apps/mobile/build/ios/iphonesimulator/Runner.app`。
