# FluxDown 1.0.28 Kotlin Android Alpha 8

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 新建任务弹窗增加可选 SHA-256 校验输入，支持 `sha256:` 前缀和 64 位十六进制校验。
- 非法 SHA-256 输入会显示中英文提示，并阻止提交；合法值透传到 Rust 队列执行最终完整性校验。
- 延续 Alpha 7 的 UI 分层、通用设置、正式签名、releaseTest 混淆修复和 11/11 协议矩阵验证。

## 本版验证

- Kotlin JVM 单测：`37/37` 通过。
- releaseTest instrumentation：`26` 项通过、`0` 失败、`4` 跳过。
- releaseTest 协议矩阵：内建协议 `11/11` 通过，落盘 SHA-256 与源文件一致；ed2k 为外部客户端移交边界。
- 发布 APK 由 GitHub Actions 使用 Alpha 7 同一正式证书签名，确保可覆盖升级；APK SHA-256 以 GitHub Release 资产为准。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 当前仍是预览包名 `dev.fluxdown.mobile.kotlin`，不做 Google Play 上架。
- 完整多音轨 rendition 选择、系统低内存回收和真实 ENOSPC 仍待后续环境验收。
