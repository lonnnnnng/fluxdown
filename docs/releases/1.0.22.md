## 主要修复

- 修复 iOS Release 流水线只补齐 `libtorrent_flutter` simulator slice、未补齐 `ios-arm64` 真机 slice 的问题。
- 构建准备脚本现在会从锁定版本对应的 Pub 缓存包恢复并校验 device 与 simulator 两套静态库及头文件，确保 simulator 和 unsigned device 构建使用完整 XCFramework。
- 保留 `1.0.21` 已加入的 symlink 缺失回退逻辑、Swift 回调生命周期修复和 CocoaPods UTF-8 环境。

## 版本与发布

- 版本号统一为 `1.0.22`，移动端版本号为 `1.0.22+23`。
- `v1.0.21` 因 unsigned device 阶段缺少 `ios-arm64` slice 未形成正式 Release；本版使用新标签，不覆盖历史标签。
- 发布流水线仍只在明确选择 `run_mode=release` 时执行；普通提交和标签推送不会自动发版。

## 验证边界

- 本地已通过脚本语法检查、symlink 缺失回退检查、CI 配置检查、Flutter analyze/test、Rust core check 和桌面前端构建。
- `v1.0.21` 已确认 simulator 构建通过，失败仅发生在 unsigned device 构建；`v1.0.22` 以全平台 Release 流水线和最终 Release 资产为发布证据。
- 当前发行签名边界未改变：Android 未配置正式签名时使用测试证书，Windows 未配置 Authenticode，macOS 为 ad-hoc，iOS 没有面向普通用户的签名 IPA。
