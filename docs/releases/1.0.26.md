## 主要变更

- 补强 Android Release 协议验收取证：自检结果写入应用专属目录，避免仅依赖不稳定的 logcat 输出。
- Torrent/Magnet 每个用例使用独立输出目录，并记录最终文件 SHA-256，避免复用已有文件造成假通过。
- 完善 Android `1.0.25` 真机协议报告、macOS 当前 GUI 回归证据、路线图和跨平台测试用例文档。
- 保留 Windows/Linux 本轮跳过边界，不把历史构建或旧版运行记录升级为当前版本真机结论。

## 验证范围

- Android Release 真机矩阵：HTTP、HTTPS、WebDAV、WebDAVS、FTP、FTPS、SFTP、SMB、HLS、Torrent、Magnet 共 11 项真实完成，ed2k 按无外部 handler 预期失败。
- macOS：`npm run verify:macos` 和当前 `.app` 前台 GUI 协议回归通过，DMG、CLI、队列控制、P2P、许可证和 CI 门禁通过。
- Android APK、AAB、iOS 验证包以及 Windows/Linux 构建产物由手动 Release 流水线生成并执行产物门禁；Windows/Linux 本轮不做本机真运行宣称。
