# FluxDown 1.0.28 Kotlin Android Alpha 6

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 新增 `releaseTest` instrumentation 变体，使用 Release 的 R8/资源收缩规则和独立包名，可在混淆后的 Android APK 上执行真机回归。
- 修复 ReleaseTest 启动时 AndroidX tracing、Kotlin runner 类被 R8 裁剪或重命名导致的运行时崩溃；测试专用保留规则不进入正式 Release。
- 收口 Torrent/Magnet metadata、文件选择、重试和错误提示流程；metadata 或文件选择失败时保持当前弹框并显示具体错误，不创建空任务。
- 修复 HTTP 种子读取和 Tracker/Peer 下载链路，继续使用 Rust metadata/file selection 与队列执行；任务列表显示资源目录，详情页显示已确认文件。
- Release APK 继续启用 R8 与资源收缩，只打包 `arm64-v8a`，产物约 `24 MB`。

## 验证范围

- Rust core：`118/118` 项通过；Rust FFI：`14/14` 项通过。
- Kotlin JVM 单测、默认 Debug connected instrumentation 通过：`24` 项通过、`3` 项按环境跳过、`0` 失败。
- ReleaseTest 真机 HTTP 回环通过；局域网 Torrent/Magnet 重复入队通过，覆盖 metadata、文件选择、Tracker/Seeder、Peer 下载和选中文件校验。
- Redmi Note 8 Pro（serial `wsvwypiz7xwslvl7`）完成 Release APK 启动和真实下载验证。
- APK 使用 Android Debug 证书，仅用于迁移预览和真机测试，不代表正式商店签名。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 完整多音轨 rendition 选择、系统低内存回收、真实 ENOSPC 和正式商店签名仍待后续环境验收。
