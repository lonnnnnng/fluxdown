## 主要功能新增

- Torrent/Magnet 获取 metadata 后，桌面新建任务支持文件树多选；任务详情显示真实文件结构、分文件已下载量、进度和采样速度，已完成文件可直接打开，并对落盘路径做安全校验。
- 移动端完善 Torrent 文件夹详情和多文件选择，保存选择结果；文件夹任务可以进入查看具体内容并预览已落盘文件。
- Android/iOS 共用的新建任务界面补齐 HLS 清晰度选择和“保留 TS”配置；CLI、FFI、任务持久化和移动下载器使用同一组参数。
- 桌面与 CLI 的保存位置支持原生目录选择和一致的路径回显，新建任务仍可覆盖默认保存位置。

## 下载与可靠性优化

- 下载失败按认证、权限、磁盘、资源失效、无 peer、网络超时和服务端临时错误分类；只有瞬态错误进入自动重试，不可恢复错误直接给出可操作提示。
- 启动时将异常中断遗留的 `running` 任务恢复为可继续的 `paused` 状态；暂停、取消和分块下载的中断处理覆盖 HTTP、HLS、FTP、SFTP、SMB 与 Torrent 路径。
- 已知总大小的下载增加截断保护，避免连接提前结束却被误判为完成；队列损坏、存储不可写和目录权限问题会保留明确错误信息。
- 跨端默认并发下载数从 `1` 调整为 `5`，下载线程数从 `8` 调整为 `16`，自动重试数从 `1` 调整为 `3`；已有用户配置保持不变。

## 安装与发行优化

- macOS DMG 改为标准拖拽安装镜像，打开后可将 `FluxDown.app` 拖入“应用程序”，不再要求每次从 DMG 启动。
- Windows、macOS、Android 三端最新界面截图已归档并更新到 README。
- 继续公开 Android APK、四个桌面安装包、三个平台 CLI 压缩包和两份许可证说明；`release-manifest.json` 改为流水线内部校验文件，不再占用公开附件。
- Release Notes 直接列出全部 10 个公开文件的字节数和 SHA-256；加上 GitHub 自动生成的两个源码包，Release 页面共 12 项。
