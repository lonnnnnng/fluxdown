## 主要变更

- 统一桌面端、Android、iOS 和 Web 预览使用桌面版 FluxDown 品牌图标。
- 新增 `icons:sync` 图标同步脚本，以 `apps/desktop/src-tauri/icons/source.svg` 为唯一品牌源，避免移动端回退到 Flutter 默认图标。
- Android 增加 round/adaptive 图标资源配置，iOS AppIcon 全尺寸资源同步更新，桌面 Web favicon 同步更新。
- 修复移动端版本检查仍显示旧版本号的问题，当前版本展示与 `pubspec.yaml` 保持一致。
- 保留 `1.0.24` Android Release 协议验收记录，以及磁力链接公共 tracker 超时修复。

## 验证范围

- `npm run icons:sync` 已执行，Android、iOS 和 Web 图标资源均来自桌面版图标源。
- `git diff --check`、Flutter 静态检查/测试、桌面前端构建和 Android Release 构建在发布流水线中执行。
- 本版本不改变下载协议和任务数据结构；协议运行结论继续以 [下载验证状态](../download-verification.md) 为准。
