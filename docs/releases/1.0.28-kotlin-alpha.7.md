# FluxDown 1.0.28 Kotlin Android Alpha 7

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- **切换为正式签名**：不再使用 Android Debug 证书，改用独立生成的正式密钥库签名；密钥为 `dev.fluxdown.mobile.kotlin` 的永久升级身份，离线备份，不提交到仓库。
- UI 分层重构：把单文件 `MainActivity.kt`（约 3,381 行）拆为 `ui/` + `viewmodel/` + `data/` + `platform/` 四层，`MainActivity.kt` 收敛到 45 行。
- 新增任务属性面板：长按任务→操作面板→「属性」，展示文件名/源链接/输出路径/协议/状态/文件大小/开始/结束时间/总耗时/平均速度/错误。
- 新增通用设置并全链路真机验证：仅 Wi-Fi 下载、下载完成通知、浅色/深色/跟随系统主题、中英双语、剪贴板链接识别、清理已完成任务并记住筛选。
- Rust 核心新增 logcat 日志通道（`fluxdown-rust`），便于真机定位协议与队列问题。
- 新增 12 类协议真机矩阵与可复跑夹具：一条 `scripts/verify-android-kotlin-protocols.sh` 跑通内建 11/11 协议，落盘 SHA-256 与源一致；ed2k 为移交边界。

## 本版验证

- Kotlin JVM 单测：`37/37` 通过。
- 本版 CI 发布 APK（versionCode `2034`）通过 `apksigner verify`，安装到 Redmi Note 8 Pro（API 36）并成功启动；APK SHA-256：`fd99236c5093ba286223a207e291b4088bfee4d02c120bfb6e6f5a0614b174d1`。证书 SHA-256：`4945a55f7683a1f8876a746f9942be9dd44afbfbe0defd6165acbfee53c96079`。
- Alpha 6 功能基线的协议矩阵记录在 `docs/android-kotlin-protocol-report-20261022.md`：内建 11/11 `finished`，落盘 SHA-256 与源一致，ed2k 为移交边界。该报告记录的测试包是 Alpha 6；本次 Alpha 7 发版没有重新执行完整协议矩阵。
- 本次尝试运行 ReleaseTest instrumentation 时，29 项中有 10 项失败，出现 `NoClassDefFoundError`（涉及 `AndroidHlsRemuxer`、ML Kit BarcodeScannerOptions、AndroidX `ContextCompat`）；混淆测试问题尚未解决，故不记为通过。
- Debug connected instrumentation 未能在保留正式签名 Release 安装的情况下运行：Debug 包与 Release 包签名不同，Android 拒绝覆盖安装。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 完整多音轨 rendition 选择、系统低内存回收、真实 ENOSPC 和正式商店分发（Google Play 上架）仍待后续环境验收。
