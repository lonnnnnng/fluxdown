# FluxDown 1.0.28 Kotlin Alpha 3

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 修复暂停后立即继续时的 Rust 队列收尾竞态，避免旧暂停协程覆盖新的排队状态。
- 完成 HLS 真机暂停、继续和最终 MP4 下载闭环验证。
- 完成 HTTP `503 -> 503 -> 200` 自动重试真机验证，确认 Kotlin 设置参数已透传到 Rust。
- 增强 HLS 分片缓存完整性校验和流式合并，补充二维码识别与多轨媒体自动化测试。

## 验证

- Android 真机：Redmi Note 8 Pro，serial `wsvwypiz7xwslvl7`。
- HLS：`index.mp4` 暂停后继续，最终 `383.2 MB/383.2 MB`，状态已完成。
- HTTP 重试：前两次返回 `503`，第三次返回 `200`，`flaky.bin` 最终 `24 B/24 B`，服务端请求次数为 `3`。
- Rust：core `112` 项、FFI `14` 项通过。
- APK：仅 `arm64-v8a`，使用 Alpha 预览签名，仅用于迁移预览和真机测试。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 完整多音轨 rendition 选择、系统低内存回收和正式商店签名仍待后续环境验收。
