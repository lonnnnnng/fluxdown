## 本次改动

- 精简公开发行资产：保留 Android APK、Windows Setup、macOS DMG、Linux DEB/RPM、三平台 CLI、manifest 和两份许可证；共 11 个上传文件，加 GitHub 自动源码包后为 13 项。
- Debug APK、Android AAB、iOS 验证包、Windows MSI、裸桌面程序和 macOS App 目录继续在 Actions Artifacts 保留，常规 Release 不再重复列出。
- 新增发布资产白名单及大小/SHA-256 校验；缺包、重复候选安装包、多余文件或内容变化都会阻止发布。中文发行说明增加按平台选择的下载入口。
- 修复 iOS Rust/C 部署目标不一致造成的 FFI 构建问题，Runner 自动按真机/模拟器架构构建并静态链接 Rust 库，最低 iOS 15.0；产物校验检查 8 个 FFI 导出符号。
- 修复移动端 FFI JSON 解码、重复解包和入参内存释放；新增真实 host Rust 库协议识别、队列及本地 HTTP 下载回归。
- 桌面 Torrent 详情增加分文件已下载量、总量、百分比和进度条；修复暂停后轮询、关闭/切换后的迟到响应覆盖，静态 metadata 不再被误认为下载进度。
- 同步中英文 README、架构、任务模型、构建说明、路线图及验证报告，明确各平台能力和旧截图的日期。
- 补齐 6 项直接依赖的许可证清单，依据当前锁定依赖的随包声明核验。

## 验证与边界

- 本地已通过 50 项 Flutter 测试（含 8 项 FFI 测试）、10 项隔离桌面 UI 回归、桌面前端构建、iOS simulator/unsigned app 构建和 FFI 导出检查。详细范围见仓库的 `docs/bugfix-verification-20260908.md`。
- 发行准备另通过 Rust workspace 144 项测试（7 项外部环境用例忽略）、8 项公开资产策略回归、Flutter 静态分析及直接依赖许可证清单检查。
- 发布流水线继续构建全部平台，只有用户下载资产进入 Release；普通 push/tag 仍不会自动触发流水线。
- 本次不是所有平台、所有协议的新一轮真机下载验收。移动端实际下载仍由 Dart/原生适配器执行，完整 Rust 引擎迁移未完成。
- 当前未配置发布签名 secrets：Android release APK 使用调试签名供安装测试，Windows 产物没有 Authenticode 签名，iOS 仅提供 CI 验证产物。macOS 正式签名/公证和商店分发仍需单独完成。
