# FluxDown 1.0.28 Kotlin Android Alpha 5

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- Rust 队列新增 HLS 已完成分片数与分片总数，缓存命中和网络下载都会持久化真实 `n/m` 进度。
- Kotlin 任务卡显示 HLS `分片 n/m`，同时保留字节进度、实时速度和完成时间；旧队列缺少字段时不显示伪造指标。
- 增加可选公网 HLS 真机回归入口，避免默认测试套件依赖外部站点。
- Release 构建继续启用 R8 与资源收缩，只打包 `arm64-v8a`，产物约 `24 MB`。

## 验证范围

- Rust core：`116/116` 项通过；Rust FFI：`14/14` 项通过。
- Android Kotlin JVM 单测、默认 connected instrumentation 和 HLS 分片指标真机回归通过；默认 connected instrumentation 为 25 项结束、2 项按环境跳过、0 失败。
- Redmi Note 8 Pro（serial `wsvwypiz7xwslvl7`）使用真实公网资源：
  `https://hd.kuktxu.com/play/dwpklmMe/index.m3u8`，通过 Kotlin → JNI → Rust 队列完成下载，任务为 `finished`，分片指标完整，输出文件非空。
- Release APK 使用 Android Debug 证书，仅用于迁移预览和真机测试，不代表正式商店签名。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 完整多音轨 rendition 选择、系统低内存回收和正式商店签名仍待后续环境验收。
