# FluxDown 1.0.28 Kotlin Android Alpha 9

## 版本性质

这是 Android Kotlin 重写预览版，只发布 `arm64-v8a` APK，包名为
`dev.fluxdown.mobile.kotlin`。桌面端、CLI、iOS 和现有 Flutter Android 版本不在本次发布范围内。

## 本版变更

- 失败原因改用稳定错误码：Rust 侧为每个失败场景给出固定 code，界面按当前语言渲染中英文案，
  英文界面不再显示中文错误；未知码仍回退 Rust 原文，不会丢信息。
- 新建任务支持选择 HLS 音频轨道：可枚举 playlist 里的 `EXT-X-MEDIA` 音轨（名称 / 语言 / 声道 / 默认标记），
  选中后音轨单独落盘为 `<视频文件名>.audio.<label>.ts`，任务属性面板可查看音轨文件路径。
  移动端没有 ffmpeg，因此音频不与视频混流，这是本版明确的产物形态。
- 韧性补齐验证：进程被杀后的断点续传、设备 Doze/idle 期间的前台服务长时下载、磁盘写满的失败提示，
  三个场景都进了可复跑脚本。
- 延续 Alpha 8 的 SHA-256 校验输入、UI 分层、通用设置、正式签名和 11/11 协议矩阵验证。

## 已知边界

- 不替换正式 Flutter Android 包，也不包含桌面、CLI 或 iOS 资产。
- ed2k 仍依赖系统外部客户端移交，不属于 Kotlin 内建下载引擎。
- 当前仍是预览包名 `dev.fluxdown.mobile.kotlin`，不做 Google Play 上架。
- HLS 音轨与视频分开落盘、不做混流；多连接下载中断后整份重下，只有单连接具备 Range 续传语义。
- 设备侧无 root，无法制造真实 `/data` 写满；ENOSPC 用 macOS 1 MiB 卷跑同一条 Rust 路径验证。
