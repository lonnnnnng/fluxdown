## 主要修复

- 修复 iOS Release 流水线在 `flutter pub get` 后尚未生成 `apps/mobile/ios/.symlinks/plugins` 时提前失败的问题。
- `prepare-ios-libtorrent-simulator.sh` 现在先从 `pubspec.lock` 读取精确的 `libtorrent_flutter` 版本；当 iOS 插件 symlink 尚未生成时，回退到同版本 Pub 缓存包，再补齐 simulator 静态库、头文件并执行 `lipo` 校验。
- 保留上一版已完成的 Swift `FlutterResult` 生命周期修复、CocoaPods UTF-8 环境和全平台构建流程。

## 版本与发布

- 版本号统一为 `1.0.21`，移动端版本号为 `1.0.21+22`。
- `v1.0.20` 因 CI 在插件 symlink 准备步骤失败未形成正式 Release；本版使用新标签，不覆盖历史标签。
- 发布流水线仍只在明确选择 `run_mode=release` 时执行；普通提交和标签推送不会自动发版。

## 验证边界

- 本地已通过脚本语法检查，并确认现有插件 slice 可被识别；本地 Flutter simulator 构建链和桌面/CLI 基础检查沿用上一轮通过结果。
- `v1.0.20` 流水线中除 iOS prepare 外的 Android、桌面和 CLI 构建任务已通过；`v1.0.21` 以全平台 Release 流水线和最终 Release 资产为发布证据。
- 当前发行签名边界未改变：Android 未配置正式签名时使用测试证书，Windows 未配置 Authenticode，macOS 为 ad-hoc，iOS 没有面向普通用户的签名 IPA。
