## 版本性质

这是移动端 Alpha 预览版本，只发布 Android `arm64-v8a` APK；桌面端、CLI 和 iOS 不在本次公开资产范围内，桌面稳定版继续使用 `1.0.27`。

## 主要变更

- 将 Android/iOS 的 Torrent/Magnet metadata 获取和文件选择迁移到 Rust FFI，新增 `fluxdown_torrent_details_async`。
- 支持种子 `name.utf-8` / `path.utf-8` 字段，移动端展示真实 Unicode 资源名和文件路径。
- 移除移动端 metadata 的 Dart/libtorrent 回退；Rust 库不可用、解析失败、超时或无可下载文件时直接显示错误，不创建错误任务。
- Android Release 继续只打包 `arm64-v8a`，APK 文件名明确标注 ABI。

## 验证范围

- `flutter analyze` 通过。
- `flutter test`：100 项通过，18 项按未注入 native 库跳过。
- 注入 macOS Rust FFI 动态库后，`test/core_ffi_test.dart` 25 项全部通过，包含本地 Torrent metadata/file selection 和真实 HTTP 队列回归。
- `cargo test --workspace`：CLI 4+37、core 106、desktop 38（8 项外部 P2P/协议夹具按预期忽略）、FFI 11 全部通过。
- 本 Alpha 未进行真实磁力真机验证；不代表 iOS 真机安装验证完成。
