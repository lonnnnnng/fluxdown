## 主要功能新增

- 设置页新增“当前版本”入口，显示当前版本号，并支持通过 GitHub Releases 检查最新版本。
- 检测到新版本时显示版本号、更新说明、Android APK 下载入口和 Release 页面入口；已是最新版本时提供“打开下载页”和“确定”。
- Android 更新检查只选择当前 Release 的 `*-android-release.apk` 资源，下载更新通过系统浏览器打开，不在应用内静默安装。

## Torrent/Magnet 与跨端同步

- 桌面端同步 Torrent/Magnet 的 metadata、目录名称、多文件选择、任务详情和逐文件下载信息。
- 桌面端补充 Torrent 暂停、继续、取消及真实控制验证夹具，移动端继续保留文件夹详情和选择结果。
- 移动端升级 `libtorrent_flutter` 至 `2.0.0`，保持现有 Torrent/Magnet 下载和文件选择入口。
- 移动端任务页与设置页继续收紧导航栏、标题和设置布局，协议详情静态入口移除。

## 可靠性与界面优化

- 更新弹框增加可滚动更新说明区域，三按钮操作区统一靠右并减少底部留白，适配长 Release Notes。
- 版本解析支持 `v1.0.19`、预发布后缀和缺失 APK 资源等情况，网络错误会通过弹框提示。
- 移动端新增更新检查解析、版本比较、Android APK 资产选择和 UI 回归测试。
