## 本次改动

- 精简公开 Assets：5 个手机/桌面安装包、3 个 CLI 压缩包、manifest 和两份许可证，共 11 个上传文件，加 GitHub 自动源码包共 13 项。内部调试包、AAB、iOS 验证包、MSI 和裸桌面程序仍留在 Actions Artifacts。
- 在不删除协议和 Android 架构的前提下压缩体积：Rust 启用 Thin LTO、单代码生成单元和符号裁剪；Android/iOS 分离 Dart 调试符号；删除未使用的 Cupertino 图标字体；提高 DMG/RPM 压缩等级，CLI 使用 ZIP/TAR.GZ 分发。
- Android Release 已由 Flutter 启用 R8 代码混淆与资源裁剪。本次继续保留 arm64-v8a、armeabi-v7a、x86_64，Dart 符号及 Android R8 mapping 单独归档，不启用会改变 Dart 标识符的额外混淆。
- 修复队列跨进程写入竞态：同时运行的 CLI 可能丢失新增任务，或让进度写回覆盖删除操作；现使用稳定旁路文件锁保护读改写，删除任务的收尾不再记作完成。
- 包含上一轮 iOS 部署目标/Runner FFI 链接、移动端 FFI JSON 解码和内存释放、桌面 Torrent 分文件进度与轮询竞态修复；同步 README、架构、验证和发行文档。

## 验证与边界

- `v1.0.15` 发版尝试在 Linux CLI 跨进程删除回归处失败，未发布 Release；保留原标签和流水线记录，不覆盖历史。本版包含针对该问题的修复及新增回归。
- 包体优化不改变下载协议、最大带宽、原生扫码、保存位置或 Android ABI 范围；没有为了减包改成 `panic=abort` 或移除移动下载引擎。
- 调试符号分离后，Dart 崩溃堆栈需要对应 Actions Artifacts 的 `.symbols` 配合 `flutter symbolize` 还原。
- 当前未配置发布签名 secrets：Android APK 使用测试签名，Windows 未做 Authenticode，macOS 仅 ad-hoc 签名；iOS 尚无普通用户可安装发行包。不是全平台、全协议的新一轮真机验收。
