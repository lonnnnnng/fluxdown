# 路线图

本文区分已落地能力与后续建设方向。核对日期为 2026-09-08，当前版本为 `1.0.16`，见 [发行说明](releases/1.0.16.md) 和 [修复验证报告](bugfix-verification-20260908.md)。历史测试通过不等于当前源码所有平台已回归。

## 近期

- 已补齐顶层 `LICENSE`、人工维护的第三方许可证清单、轻量清单校验和 Release 随包许可证文本；后续补完整传递依赖 license bundle 和更严格的依赖审计。
- 已将根 README 收敛为短快速开始、截图和关键文档入口；详细构建、签名、产物和 CI 信息继续维护在 `docs/`。
- 已完成桌面端两页式 UI 重构：下载列表采用紧凑状态侧栏、横向指标栏和高密度任务行，设置页统一分组和字号；任务行支持点击开始/暂停及右键、长按、三点菜单操作。
- 已统一桌面端和移动端的天蓝色/白色主题与常规字重，并完成 macOS 原生窗口和 Android 真机 release UI 截图复验。
- 已为桌面队列路径接入平台原生数据目录：macOS 使用 `~/Library/Application Support/FluxDown/queue.json`，Windows 使用 `%APPDATA%/FluxDown/queue.json`，Linux/Unix 保持 XDG 路径；macOS 会兼容读取旧版 `~/.local/share/fluxdown/queue.json`。
- 已增加 URL 凭据脱敏，CLI JSON 输出、命令错误、桌面属性页和任务错误展示不再暴露 URL 中的用户名和密码；原始队列数据仍保留真实链接用于下载和复制。
- 已增加下载文件名规范化，CLI/桌面端会把用户另存名、协议推断名和旧队列文件名收敛为单文件名，避免异常文件名写出保存目录。
- 已为桌面 CLI、桌面 GUI command、Rust 核心及移动端增加按任务 SHA-256 文件校验；新建任务可配置期望 hash，校验失败按失败处理。
- 扩展 CLI 集成测试，覆盖队列生命周期和更多协议检测样例。
- 为 HLS、FTP、SFTP、SMB 增加更多边界单元测试。
- 为移动端 App 增加协议下载 mock 测试和队列恢复测试。

## 已落地能力

- `1.0.10`：移动端新建弹框已恢复标题栏扫码和剪切板入口，不再作为待实现项。
- `1.0.12`（桌面）：更新检查、安装包下载和窗口尺寸持久化。
- `1.0.13`（桌面/core）：任务 ETA 与每任务限速，任务配置优先于全局配置；限速字段历史命名与实际字节单位见 [任务模型](task-schema.md)。
- `1.0.13`（桌面/core）：Torrent 文件清单、tracker、peer、会话速率/ETA 和后端分文件进度快照。`1.0.16` 补上前端分文件进度展示，以及关闭/切换/暂停后的轮询控制；静态 metadata 不代表已下载进度。
- `1.0.13`（桌面/core）：HLS variant 选择、分片缓存恢复、可选保留 TS。移动端仍有独立 HLS 下载路径，不代表这些可配置项已同步移动 UI。
- `1.0.13`（移动端）：任务模型与新建 UI 增加 SHA-256，下载完成后校验单文件产物。
- `1.0.14`（桌面）：系统托盘、关窗驻留、单实例、完成/失败系统通知、可关闭的剪贴板监听。
- FFI 分阶段接入：`1.0.13` 增加 C ABI 和 Dart 投影；后续源码接入 FFI 优先的协议识别。`1.0.16` 补齐 JSON 解码、避免重复解包、内存释放和 iOS Runner 静态链接，本地测试/构建通过。它不等于统一队列格式或移动下载引擎迁移完成。
- `1.0.16`（发行）：公开下载收敛到 11 个上传文件，含自动源码包共 13 项；内部验证产物仍保留 CI，新增白名单、缺包和完整性回归。
- `1.0.16`（可靠性/包体）：跨进程文件锁保护队列读改写；Rust 链接裁剪、Dart 符号分离、未使用字体清理及 CLI/安装包压缩，保留协议和 Android ABI 范围。

## 中期待完成

- 移动端下载控制器切换到 Rust core：补非阻塞执行、进度/取消接口、并发/线程/重试/限速设置透传、独立队列转换及迁移测试。现有同步 `queueRun` 不能直接替换 Flutter 控制器。
- 在 Android/iOS 目标设备验证新 FFI 库实际加载，重跑当前版本完整协议下载；补 iPhone 真机与 Linux GUI 缺失的运行证据。
- 每次明确打包/发版时复验 iOS 在 CI Xcode/SDK 下的构建及最终导出符号，结果独立于 App 真机运行证据记录。
- ed2k 增加更明确的外部客户端配置和状态回传能力。

## 长期

- 跨设备队列同步和远程控制。
- 浏览器扩展或系统分享扩展，用于快速添加下载任务。
- 远程 Web 控制台和 headless daemon。
- 插件化协议后端，让高级用户接入 aria2、yt-dlp 或企业内网后端。
- 更完整的后台下载体验，尤其是 Android foreground service 和 iOS 后台策略。
- 商店分发材料：隐私政策、许可证页面、合规说明和自动化截图。

## 技术债

- 移动端和桌面端下载执行仍存在两套实现，长期维护成本较高；FFI 协议识别与原生队列独立测试仅完成收敛前置工作。
- JSON 队列适合早期和本地调试，但多进程并发和 schema migration 能力有限。
- 当前错误分类主要面向开发者，用户可读性还需要增强。
- Release 产物校验已有基础；Windows 条件签名脚本、Android/iOS 凭据配置入口已存在，但实际正式签名/商店分发及 macOS 公证仍需单独核验，不能以脚本存在判断已就绪。
- 许可证清单已有轻量校验，但完整传递依赖 license bundle、依赖审计和 GitHub Actions 阻断项仍未完成。
